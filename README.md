# hr-magazine-writing-skill

HR 전문지에 실을 기고문을 그 지면의 문체와 구성에 맞춰 쓰고 다듬는 Claude 스킬입니다.

월간 「인재경영」 특집 기고 69편(2025년 12월~2026년 11월)을 분석해 규칙을 뽑았습니다. 전문이 공개된 16편을 여섯 가지 기준으로 견주어 잘 쓴 글을 골랐고, 그 글들의 공통점과 매체 전체에서 흔한 약점을 정리했습니다.

## 무엇을 해 주나

- 제목, 도입, 소제목, 문단, 근거, 맺음을 이 지면의 관습에 맞춰 씁니다.
- 시대 진단으로 여는 도입, "결국 사람이다"로 끝나는 맺음처럼 여러 글에 되풀이되는 표현을 피합니다.
- 자기 회사 사례와 데이터를 홍보로 읽히지 않게 쓰는 법을 적용합니다.
- 초안을 쓴 뒤 점검표로 스스로 확인하고 고칩니다.

## 설치

Claude Code가 설치된 컴퓨터의 터미널에서 아래 두 줄을 실행합니다.

```bash
git clone https://github.com/ejlee-0924/hr-magazine-writing-skill.git
cp -r hr-magazine-writing-skill/hr-magazine-writing ~/.claude/skills/
```

Claude Code를 다시 열면 스킬 목록에 `hr-magazine-writing`이 보입니다.

Claude 앱(claude.ai)에서 쓰려면 `hr-magazine-writing` 폴더를 zip으로 묶어 설정의 스킬 메뉴에서 올립니다.

## 쓰는 법

평소처럼 요청하면 됩니다.

- "인재경영 12월호 특집 기고 초안 써 줘. 주제는 ○○이고 재료는 이 파일이야."
- "이 원고를 HR 잡지 기고문 스타일로 다듬어 줘."
- "이 글의 제목과 도입을 세 가지 안으로 뽑아 줘."

필자만 가진 재료(자기 회사 데이터, 직접 한 일, 현장에서 들은 말)를 함께 주면 결과가 좋아집니다.

## 폴더 구성

```
hr-magazine-writing/
├── SKILL.md                 쓰는 순서, 규칙, 자가 점검표
└── references/
    ├── abouthr.md           월간 인재경영 매체 통계와 기준 글 목록
    └── examples.md          규칙별 짧은 예
```

## 알아 둘 점

- 분석한 매체는 월간 「인재경영」 하나입니다. 다른 매체에 쓸 때는 그 매체의 최근 글을 먼저 확인하세요.
- 기고 원문은 이 저장소에 없습니다. 규칙과 한 문장 이내의 짧은 예만 담았고, 원문은 매체 사이트에서 읽을 수 있습니다.
- 유료회원 전용 구간은 분석하지 않았습니다. 구성과 맺음 규칙은 전문이 공개된 16편을 기준으로 합니다.
